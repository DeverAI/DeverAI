# dev_log 2026-09-05 v8.27 — 真·算力漂移：服务器端续算

## 背景（用户四项裁决）
①密钥同样传服务器但必须加密（MQTT 不采用）→ AES-GCM/Fernet 信封（sync_password 派生、盐内嵌），服务器仅存密文，续算端解密到内存；安全红线「API Key 仅本机」修订为「本机明文、自有服务器仅密文信封」。②不看守模式：不使用提问/审批工具，能做的做完，没做完的保留进度。③轮边界断点上传会话，服务器以普通端 CLI 继续同一会话；工作区素材化到 APPDATA，WorkTree 等数据同步到对应位（绝不入工作区）。④退出时选上传模式（最简/完整）并记住不再问。

## 改动清单
### A. 密钥信封（pyqt/desktop/sync.py）
- `export_keys_envelope` / `import_keys_envelope`：六字段信封 `{"v":1,"kind":"deverai-keys","salt","tok"}`（内嵌随机盐 PBKDF2 + Fernet(zlib)，不依赖本机 sync_salt.bin）；无 cryptography 时 **fail-closed 返回空**（拒绝降级混淆），服务器端走既有 drift_api_key 兜底。
- `push_to_server` 新签名：`upload` 参数（"auto"/"minimal"/"full"/""）+ body 增 `pid`/`keys_enc`/`ws_zip`/`data_zip`/`upload_mode`；httpx 超时 30→120s；sync_queue 普通冲刷不传 upload（避免周期全量推送）。
- `build_drift_upload`（minimal=工作区 mtime 增量，基准 `data/drift_last_push.json`；full=全工作区；两者附 data 子集 checkpoints/audit/记忆/工作区设置/保护状态/终端池——绝不入工作区；排除集同一键备份；64MB 上限）+ `mark_drift_pushed`。

### B. 不看守模式
- `pyqt/desktop/tools.py`：`_unattended_note`（危险动作跳过 → 工作区 `unattended_progress.json` 台账，随快照往返）+ `_request_approval` 顶部最高优先分支（ENABLE_UNATTENDED：非危险自动放行 / 危险跳过记账，绝不阻塞）。
- `pyqt/desktop/agent.py`：`UNATTENDED_RULES` 提示词（禁提问/自行判断/能做做完/汇报分「已完成/未完成（原因）」），随 ENABLE_UNATTENDED 注入。
- `pyqt/desktop/config.py` + `settings_dialog.py`：`ENABLE_UNATTENDED`（默认 False）、`drift_upload_mode`（默认空）三层贯通。

### C. 上传模式（pyqt/desktop/gui.py）
- `_ensure_drift_upload_mode`：漂移退出首次询问「最简（WorkTree 即时变更增量）/完整（所有工作区文件）」+「记住选择」勾选（默认开）；记住即写 config 永久生效不再问，不勾选仅本轮内存生效。
- DriftThread push：`upload="auto"`、wait_for 10s→90s（大包上传）。

### D. 服务器素材化（sync_server.py）
- `DRIFT_WS_DIR`（Windows `%LOCALAPPDATA%\DeverAI\drift`，`SYNC_WS_DIR` 覆盖）`/<项目号>/`：`workspace/`（素材化工作区）+ `data/`（WorkTree/记忆/设置位）+ `keys.enc`（仅密文）+ `snapshot`（续算读历史）+ `latest.txt`；同项目号重复推送原地刷新。
- `_safe_extract_zip`：zip-slip 防护（拒绝绝对路径/`..`/逃出目标目录）。
- `/push` 扩展（pid/keys_enc/ws_zip/data_zip/upload_mode → 素材化，返回 `materialized`）；`/drift/status` 增 `drift_ws`（dir/latest/resume_hint 续算指引）。

### E. 续算接力（pyqt/cli_main.py）
- `--unattended`：ENABLE_UNATTENDED 强制开。
- `--from-drift <dir>`：读 `snapshot`（getpass 口令解密，失败回落明文/冷备）→ 载入会话历史；读 `keys.enc` 解密**到内存**（不落盘）；无信封走服务器本地 drift_api_key；快照内非敏感配置（temperature/max_tokens/agent_mode）接力。

## 使用方式（部署侧）
1. 退出 DeverAI 选「算力漂移退出」→ 首次选上传模式（记住）→ 推送（快照+工作区+data 子集+密钥信封）。
2. 服务器：`/drift/status` 读 `drift_ws.resume_hint` → `python pyqt/cli_main.py --workspace <dir>/workspace --from-drift <dir> --unattended` → 输入 sync_password（解密历史与密钥到内存）→ Agent 在服务器继续同一会话真实干活。
3. 回本机：开机自动拉取合并（既有 /pull 流程）。
