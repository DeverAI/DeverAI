## 本轮改动

### 1. sync_server.py 补建（第四端，算力漂移服务器）
- 快照存取：`POST /push`、`GET /pull`（桌面 zlib/base64 冷备与网页 web-cold 信封
  **双格式**原样写回，决策 106）
- 冷备 Agent 续聊：`POST /chat`（读 → LLM → 写三段式 `_CHAT_LOCK`，每轮 unacked_count+1；
  加密主快照永不降级，决策 79）；`GET /chat/history`
- 漂移状态机：`/drift/begin|status|finish`（drift_state.json 原子写）
- 远程指挥：`/cmd/register|poll|heartbeat|result|dispatch|nodes|results`
  （队列 maxlen=100、节点 TTL 2min、结果 TTL 10min、/cmd/result 体限 1MB）
- 鉴权门（决策 99）：未设 SYNC_TOKEN 仅环回可访问；XFF 存在强制令牌；令牌模式下
  无/错令牌 401；CORS 收紧为环回源；/push 体限 64MB
- HTML 状态页 `/` 与 `/chat/page`：零 CDN、无 emoji（纯文本标记）
- LLM 直连：DRIFT_API_BASE/DRIFT_API_KEY/DRIFT_MODEL/DRIFT_ALLOW_LOOPBACK 环境变量
