## 改动清单
### A. 新模块 pyqt/desktop/uploads_ingest.py（不依赖 Qt）
- `alloc_dest(ws, filename, actor)`：分配 `uploads/<ts>-<actor>/<名>`；只取 basename 防路径成分；
  同目录同名自动加序号；工作区不存在/敏感名返回 (None, 原因)。
- `ingest_file(ws, src)`：普通文件校验（非目录/非符号链接）→ `MAX_UPLOAD_BYTES=512MB` 上限 →
  copy2 入区（失败清半截）；敏感名拒绝（config.json/err.log/api.txt/api_keys.py/.env + .pem/.key/.pfx/.p12，
  与 sync.build_drift_upload excl_name 同源防密钥绕道入区）。
- 入区即受既有链路覆盖：用户文件保护/命名规则/一键全量备份/drift manifest+增量（mtime）。

### B. checkpoint 跳过 uploads/（Future.md 约束：防 C 盘膨胀）
- checkpoint.py `save_checkpoint` / `save_checkpoint_bytes`：rel 为 `uploads` 前缀直接返回 None。
- 安全网不变：session_snap 整包、一键备份 `backups/<ts>_full.zip` 仍覆盖 uploads/。
- 网页版同源受益（snap_bridge 复用 desktop.checkpoint）。

### C. gui.py 拖拽/粘贴接线（MainWindow）
- `setAcceptDrops(True)` + `dragEnterEvent/dropEvent`：本地文件 URL → `_ingest_paths`。
- 输入框 `setAcceptDrops(False)`（拖放统一上浮窗口级）+ `installEventFilter`：
  Ctrl+V 时剪贴板含本地文件 URL → 入库；含图片 → `_ingest_clipboard_image`（QImage 落 PNG 到
  `uploads/pasted-<ts>.png`，用 alloc_dest 分配，复用同一套敏感名/序号逻辑）；纯文本粘贴走默认。
- `_ingest_paths`：逐个 ingest → 成功挂引用条（**指针式引用**：内容=`[文件已入库工作区：<rel>]（AI 可用
  read_file 读取…；二进制用户资产走 copy_user_asset 工作副本语义）`，不内嵌 50KB 文本——文件已在工作区，
  AI 自取）；失败 statusBar 提示原因（敏感名/超限/源无效）。
