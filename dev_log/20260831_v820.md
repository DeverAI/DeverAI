## 二、阶段2+3：前端结构与响应设计联合优化

### 2.1 移除 UI chrome 渐变（用户明确要求避免渐变风格）

- `.ln-avatar`：linear-gradient → 纯色 `var(--accent)` + 边框几何化。
- `.auth-logo`：linear-gradient → 纯色 + 边框。
- `.hero-title`：文字 `background-clip:text` 渐变 → 纯色 `var(--text)`。
- 保留 Siri 吉祥物彩球的 radial-gradient（属装饰艺术内容，非 UI chrome）。

### 2.2 CSS 变量驱动三栏布局（几何边界 + 可拖动分隔条）

- `:root` 新增：`--nav-w:260px` / `--right-w:320px` / `--gutter:1px` / `--gutter-hit:6px`
  / `--accent-deep:#1d4ed8`（浅色主题补齐，原仅深色定义）。
- `#left-nav` / `#right-panel` 宽度改用 `var(--nav-w)` / `var(--right-w)`，附
  `min-width`/`max-width` 硬边界。
- 分隔条用 `::after` 伪元素：视觉宽 `--gutter`，命中宽 `--gutter-hit`（命中区大于
  视觉区便于抓取），`cursor:col-resize`，`z-index:5`。
- 媒体查询断点改用 CSS 变量：900px → `--nav-w:220px;--right-w:0`，700px → 单栏。

### 2.3 统一指针事件 + 缩放拖动（main.js `initResizableGutters`）

- `pointerdown`/`pointermove`/`pointerup`/`pointercancel` + `window.blur` 兜底，
  兼容鼠标/触摸/笔。
- 边界 clamp：左栏 200–360px，右栏 240–560px，主区至少占视口 30%（`MAIN_MIN_RATIO`）。
- 拖动中 `document.body.style.userSelect='none'` 防选中；`e.buttons===0` 兜底
  pointerup 丢失。
- 宽度持久化到 `localStorage`（`deverai.gutters.v1`），刷新后 `loadGutterPrefs` 恢复。

### 2.4 DOM 语义 / ARIA / 键盘可达性

- `#left-nav` 加 `role="navigation" aria-label="工作区导航"`。
- `#right-panel` 加 `role="complementary" aria-label="上下文面板"`。
- 静态 `.ln-item`（nav-assets/experts/trace/devtools/ln-doc-*）：`role="button"`
  `tabindex="0"`。
- 动态 `.ln-item`（renderTaskLists）：同上 + `aria-label="切换到会话：xxx"`。
- 键盘：Enter/Space 触发 click（静态项在 wireup 挂 onkeydown，动态项在渲染时挂）。
- `:focus-visible` 焦点环扩展到 `.ln-item`/`.ln-link`（原仅 btn/icon-btn/rh-tab 等）。

## 五、教训

1. **当前 shell 的 Python 不一定是项目 Python**：miniforge3 base 未装 PyQt6/
   fastapi/uvicorn，直接跑 `_audit_tmp.py` 会误判后端坏掉。项目 Python 在
   `C:\Users\david\AppData\Local\Programs\Python\Python312\python.exe`。
   test_smoke_servers 用 `sys.executable` 起 Popen，对启动 Python 敏感。
   → 后续跑回归须显式用项目 Python，不能依赖 shell 默认环境。
2. **渐变清理要区分 UI chrome 与装饰内容**：Siri 彩球的 radial-gradient 是
   动画艺术内容，移除会破坏吉祥物身份；UI chrome（按钮/头像/标题）的渐变
   才是要清理的对象。
3. **可拖动分隔条的命中区设计**：视觉宽度 1px 难抓，命中区放大到 6px（伪元素），
   命中区大于视觉区是工业级拖动条的通行做法。
