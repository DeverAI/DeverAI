# v8.23 浏览器直控（CDP）+ 外部软件（exe）自动化工具

日期：2026-08-31 | 版本：8.23.0 | 范围：webui 前后端 + pyqt/desktop 底层修复

## 背景

用户要求补齐"浏览器操作 + 软件操作"两类主要工具并验证。调研发现：桌面版有完整
实现（browser_ctl CDP / win_automate exe 自动化），但**网页版完全没有这两类工具**。

## 变更清单

### 后端（webui/app/bridge.py）
- 新增 POST /api/bridge/browser_ctl：launch/navigate/click/type/press_keys/close 六动作，
  复用 pyqt.desktop.browser_ctl（CDP，127.0.0.1 调试口，独立临时 profile）。回显经
  _redact_ws 脱敏。
- 新增 POST /api/bridge/exe：launch/list_windows/screenshot/click/type/press_keys/
  bring_to_front/close/journal 九动作，复用 pyqt.desktop.win_automate。
  服务端硬闸：close 白名单（仅本桥 launch 启动的 pid/hwnd，终止即出名单）；
  click 坐标越界+绝对上限 20000 双重拒绝；screenshot 受保护目录约束；所有动作落
  journal（webui DATA_DIR/ui_automation_journal.jsonl）。
- **关键修复**：bridge.py 模块级把 repo 根插入 sys.path——此前服务以 cwd=webui
  启动时 `from pyqt.desktop import ...` 懒导入必然 ModuleNotFoundError（500），
  现有 browser_read/browser_screenshot 端点同样中招（此前无测试覆盖故未暴露）。

### 底层修复（pyqt/desktop/）
- **browser_ctl.py Critical 修复**：_do_launch 缺 `global _SESSION` 声明，会话只写入
  局部变量——launch 返回成功后 navigate/click/type 全部报"尚未启动浏览器"。
  桌面版与网页版同源中招（桌面版此前无 CDP 链路测试覆盖）。
- **win_automate.py 增强**：新增 _grab_win32 纯 GDI 截图回退（PrintWindow
  PW_RENDERFULLCONTENT → QImage 保存 PNG，无需 QApplication）。此前 webui/服务器
  场景无 Qt 主线程，窗口截图必失败。

### 前端（webui/static/js/）
- tools.js：15 个新工具定义 + 执行实现（browser_launch/navigate/click/type/
  press_keys/close + exe_launch/list_windows/screenshot/click/type/press_keys/
  bring_to_front/close/journal）。
- 审批策略：browser_launch 与 exe_launch/click/type/press_keys/close（真实桌面
  操作）标记 dangerous → 走 requestApproval 强制用户弹窗；受控浏览器内部操作
  （navigate/click/type，隔离实例低风险）与只读操作（list_windows/screenshot/
  journal）免审批。
- 三层贯通：ENABLE_EXE_AUTOMATE 新开关（core.js DEFAULTS → tools.js gated →
  panels.js SWITCHES）；browser_ctl 系列复用 ENABLE_BROWSER_CTL；exe_journal
  复用 ENABLE_EXE_JOURNAL。
- agent.js：系统提示补浏览器直控与外部软件操作规范（先截图看清再点）。

### 冒烟测试（tests/test_smoke_servers.py）
- 新增 16 项断言：browser_ctl/exe 未知操作 400、未启动会话失败契约、list_windows
  契约、launch 不存在路径失败、click 越界拒绝、close 白名单外拒绝、journal 契约、
  type 缺参 400 等（全部安全路径，不真实操作桌面/浏览器）。

### 缓存版本
- index.html：tools/core/agent/panels bump ?v=8.23.0。

## 故障库新增（AGENTS.md）
1. pyqt/desktop/browser_ctl.py `_do_launch` 缺 global（存量 Critical，靠真实链路验证暴露）。
2. webui 以 cwd=webui 启动时 pyqt.desktop.* 懒导入 500（sys.path 前置插入修复）。
3. app_shot._grab 无 QApplication 即 False——服务器场景截图需 Win32 回退。

## 教训
- "工具定义齐全 + 单元断言通过"≠"能用"：browser_ctl 的 global bug 只有真实跑一遍
  launch→navigate 链路才暴露。新工具必须真实端到端调用一次再收口。
